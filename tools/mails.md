# E-mails automatiques de trouvetavoie

Envoyés depuis trouvetavoie2027@gmail.com par la tâche programmée (une fois par heure, de 8 h à 22 h, heure de Paris).
La tâche lit `GET https://trouvetavoie.pages.dev/api/admin` (clé `ADMIN_CLE`), envoie les e-mails ci-dessous,
puis marque chaque envoi avec `POST /api/admin {action:'fait', pi, type}` pour ne jamais envoyer deux fois.

Vouvoiement (l'acheteur peut être un parent). Signature : « L'équipe trouvetavoie ». Jamais de nom propre.

## 4. Réponses aux messages reçus (BROUILLONS seulement, jamais envoyés)

Pour chaque nouveau message écrit par une personne (pas les e-mails automatiques : Google, Stripe, no-reply, newsletters) :
- préparer un brouillon de réponse dans la même conversation, que le propriétaire relit et envoie lui-même ;
- poli, simple, chaleureux ; vouvoiement, sauf si la personne tutoie (souvent un lycéen) ;
- répondre seulement avec ce qui est vrai sur le site : offres, prix, contenu, « Mon accès », « Mot de passe oublié » ;
- ne jamais promettre une admission, un remboursement ou un geste commercial : écrire une réponse neutre et le signaler au propriétaire ;
- signer « L'équipe trouvetavoie » ;
- mettre le libellé « trouvetavoie/brouillon-prêt » sur la conversation pour ne pas la traiter deux fois.
